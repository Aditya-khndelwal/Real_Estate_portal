# EquityHouse Stage 7

Vite + React + Tailwind implementation of the Fractional Real Estate Marketplace and Property Detail UI.

## Run

```bash
npm install
npm run dev
```

Open `/properties` for the marketplace or `/properties/bandra-skyline` for a detail view.

The mock data in `src/data/properties.js` matches the current backend property shape. Replace it with API requests when the backend integration is ready.
